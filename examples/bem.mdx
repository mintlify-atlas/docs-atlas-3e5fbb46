---
title: BEM
description: Use CVA with BEM (Block Element Modifier) class names to manage modifier classes with type safety.
---

CVA maps naturally to the BEM modifier pattern. Your base class becomes the `cva` base, and each modifier becomes a variant value. CVA handles the logic of combining them — you just pass the variant props.

## Variant function

```typescript components/button.ts
import { cva, type VariantProps } from "class-variance-authority";

export const button = cva("button", {
  variants: {
    intent: {
      primary: "button--primary",
      secondary: "button--secondary",
    },
    size: {
      small: "button--small",
      medium: "button--medium",
    },
    disabled: {
      true: "button--disabled",
      false: null,
    },
  },
  compoundVariants: [
    {
      intent: "primary",
      disabled: false,
      class: "button--primary-interactive",
    },
  ],
  defaultVariants: {
    intent: "primary",
    size: "medium",
    disabled: false,
  },
});

export type ButtonVariantProps = VariantProps<typeof button>;
```

## Stylesheet

```css components/button.css
.button {
  font-weight: 600;

  cursor: pointer;
}

  border-color: transparent;

  font-size: 1rem;

```

## Usage

```typescript
button({ intent: "primary", size: "medium" });
// => "button button--primary button--medium button--primary-interactive"

button({ intent: "secondary" });
// => "button button--secondary button--medium"

button({ intent: "secondary", disabled: true });
// => "button button--secondary button--medium button--disabled"
```

<Note>
  Setting a variant value to `null` (as with `disabled: { false: null }`) tells CVA to add no class for that combination. This keeps your output clean — the `false` case for a boolean modifier produces no extra class.
</Note>

## Compound variants with BEM

Compound variants let you apply a modifier class only when a specific combination of other modifiers is active. In the example above, `button--primary-interactive` is applied only when `intent` is `"primary"` and the button is not disabled — a pattern that is awkward to express in plain CSS without extra specificity.

```typescript
// Compound variant entry
{
  intent: "primary",
  disabled: false,
  class: "button--primary-interactive",
}
```

<Tip>
  BEM modifier classes are plain strings, so you can use this same approach with any CSS methodology that uses a string-based naming convention — SMACSS, ITCSS, or your own conventions.
</Tip>
