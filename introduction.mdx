# Class Variance Authority

**CVA** helps you build type-safe, composable component variants for any CSS approach — Tailwind CSS, CSS Modules, BEM, or plain CSS classes.

CSS-in-TS libraries like [Stitches](https://stitches.dev) and [Vanilla Extract](https://vanilla-extract.style) are fantastic for building type-safe UI components, but they aren't for everyone. You may need full control over your stylesheet output, work with Tailwind CSS, or simply prefer writing your own CSS.

Creating variants with traditional CSS can become tedious: manually matching classes to props, managing combinations, and adding TypeScript types by hand. `cva` takes those pain points away so you can focus on building.

## A quick taste

```typescript
import { cva } from "class-variance-authority";

const button = cva(["font-semibold", "border", "rounded"], {
  variants: {
    intent: {
      primary: ["bg-blue-500", "text-white", "border-transparent"],
      secondary: ["bg-white", "text-gray-800", "border-gray-400"],
    },
    size: {
      small: ["text-sm", "py-1", "px-2"],
      medium: ["text-base", "py-2", "px-4"],
    },
  },
  defaultVariants: {
    intent: "primary",
    size: "medium",
  },
});

button();
// => "font-semibold border rounded bg-blue-500 text-white border-transparent text-base py-2 px-4"

button({ intent: "secondary", size: "small" });
// => "font-semibold border rounded bg-white text-gray-800 border-gray-400 text-sm py-1 px-2"
```
